Worth knowing before the day
  • NSO 6.7 in the hiTech007 lab, 6.5 in the exam. The Python API is unchanged.
  • Python 3.12 in the lab, 3.13 in the exam.
  • GitLab 18.9 in the lab, 18.4 in the exam.
  • The exam workstation runs GNOME; the lab runs XFCE. Same tools, different appearance.
  • ⚠️ The exam gives you this documentation inside the workstation. The lab workstation has no internet, so read this page on your own machine — and be aware that on the day you will not be able to switch to a second screen for it.
